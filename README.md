# Cat Rescue in Buckinghouse

Juego de plataformas 2D desarrollado como proyecto web.

Natalia debe recorrer el patio de Buckinghouse, rescatar a siete gatos y evitar los obstáculos del escenario. Los gatos rescatados se unen a una caravana y siguen al personaje principal.

## Ejecutar localmente

Este proyecto es un sitio web estático.

Desde la carpeta raíz, ejecutar:

```bash
python -m http.server 5500
